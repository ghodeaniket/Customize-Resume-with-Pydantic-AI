# Archived Documentation

This directory contains archived documentation, verification scripts, and testing files that are no longer actively used in the Resume Customizer project but are kept for historical reference.

## Contents

### Documentation
- `CHANGES.md` - Historical change log
- `FILE_UPLOAD_FIX.md` - Documentation of file upload issue fixes
- `FIX_DOCUMENTATION.md` - Documentation of critical fixes
- `IMPROVEMENTS.md` - Historical improvement suggestions
- `PHASE2_VERIFICATION.md` - Phase 2 verification report
- `PHASE3_DOCUMENTATION.md` - Phase 3 documentation
- `REFACTORING.md` - Documentation of refactoring changes

### Verification Scripts
- `verify_all_fixes.py` - Verification script for all fixes
- `verify_fixes.py` - Basic verification script
- `verify_openrouter_integration.py` - OpenRouter integration verification
- `verify_refactoring.py` - Refactoring verification
- `verify_upload_fix.py` - File upload fix verification
- `verification.log` - Verification log file

### Testing Files
- `test_env.py` - Environment testing
- `test_env_vars.py` - Environment variables testing
- `test_file_boundaries.py` - File boundary testing
- `test_file_upload_fix.py` - File upload fix testing
- `test_refactoring.py` - Refactoring testing

## Notes

These files are kept for reference purposes but are no longer actively maintained. The current architecture diagrams and documentation can be found in the `/docs` directory at the project root.
